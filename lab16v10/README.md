# Лабораторна робота №16. SelectMany, пагінація та методи розширення

**Мета.** SelectMany розгортає вкладені послідовності в одну.

## Виконання роботи (варіант 10)

Створено 10 продуктів із вкладеними характеристиками й опціями. Два SelectMany об’єднують усі опції в один список. Skip і Take виводять по три продукти на сторінку. HasFeature перевіряє характеристику без урахування регістру.

## Контрольні запитання

1. SelectMany розгортає вкладені послідовності в одну.
2. Skip і Take відбирають потрібний діапазон у стабільному порядку джерела.
3. Метод розширення дозволяє викликати HasFeature без змін класу Product.

## Висновок

Демонстрація виводить 20 опцій і чотири сторінки, остання з яких містить один продукт. Пошук Size показує як збіги, так і випадок без характеристики.
